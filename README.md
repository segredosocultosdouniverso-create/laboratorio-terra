# Laboratório Terra / Earth Lab

Globo 3D interativo da Terra em um único arquivo HTML. Roda no navegador, sem instalação.
Interactive 3D Earth globe in a single HTML file. Runs in the browser, no install needed.

## O que tem / Features
- Globo com relevo, oceanos e satélite
- Interior da Terra em escala real, com gráficos
- Atmosfera, tempo e gelo
- Ficha de país: PIB, energia renovável e pobreza extrema (Banco Mundial)
- Lua, planetas e zoom até a galáxia

## Como usar / How to use
Abra o `index.html` no navegador, ou acesse a versão online (link do GitHub Pages).

## Status
